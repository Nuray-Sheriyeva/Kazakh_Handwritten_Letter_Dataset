# Kazakh_Handwritten_Letter_Dataset

Kazakh language has 42 letters (from which 33 are native to Russian as well). This dataset consists of 22662 samples of kazakh handwritten letters. 108 sheets, 42 letters repeated 5 times by each writer. Each letter (mostly) has 540 samples. Dataset is split into training, validation and test sets with 18047 (79.6%), 2310 (10.2%) and 2310 (10.2%) images respectively. No information about the writers was included in this dataset. Metadata consists of file path, label, sheet ID and set in which the letter was splitted into.


## Methodology

106 people participated to fill out the sheets. Each person could fill out only a single sheet of paper. Each sheet has a 21x12 table with 1st and 6th column reserved for a letter that needs to be filled continously for the next 5 cells:
